Seasons runs your Minecraft server in seasons on one world that never resets. At the end of a season everyone's gear goes into a Hall of Fame, everyone starts again at a fresh spawn, and the old world stays locked until the group votes for Homecoming. These docs cover installing it, running a season from start to finish, and every command, permission and setting.

## Getting help

- Search these docs with the box at the top, or press <kbd>/</kbd>.
- In game, `/season help` and `/hof help` list every command you may run, with each argument explained. Tab completion fills in the rest.
- Found a bug? [Report it on GitHub](https://github.com/gr33nMari0/seasons/issues). Found a dupe or an exploit? Never post it in public: see the [security policy](https://github.com/gr33nMari0/seasons/blob/main/SECURITY.md).
