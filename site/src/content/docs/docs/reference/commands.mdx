This list is generated from the plugins' own command trees, so it always matches the release it was built for. In game, `/season help`, `/hof help` and tab completion show the same commands, and only the ones you may run.

- **Usage** lines show each argument as `<name: what it takes>`. Words in `[brackets]` are optional. Click a line to copy the command.
- **Everyone** commands work for every player. **Ops** commands need op, or the permission node shown, which you can give a group in LuckPerms or any permissions plugin. See [Permissions](/docs/reference/permissions/).
- Positions can be typed absolute (`120 64 -30`), relative (`~ ~1 ~`) or as `here`. Boxes take two positions, or `sel` for your wand selection.
