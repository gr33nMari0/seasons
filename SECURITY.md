# Security policy

Seasons guards players' archived gear, so dupes and theft matter.

## Reporting

**Please report dupes, ways to take archived or vaulted items, ways into locked zones, permission escalation and any other exploit privately, never in a public issue.** Use GitHub's private vulnerability reporting on this repository (Security → Report a vulnerability), or email Peter Woodhead.

Include the Seasons and Paper versions, steps to reproduce, and what you expected. You'll get a reply within a week. Please give us a reasonable time to release a fix before talking about it publicly.

## Supported versions

Only the latest release gets security fixes.
